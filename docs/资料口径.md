# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

电量累计kWh，读数仅在read_at代表累计值，区间增量由有效相邻读数解释；换表使用replacement的旧末读和新底数，不将新表较小值当负耗电。wrap是已声明模数回绕，无声明的倒退待核。topology为电表物理包含关系，child缺测不等于零。每段父量减有效独立子量为公共池，若覆盖不齐或负残差则保留待核量，不得剪零分配。public_load为独立实测公共负荷证据，不能与父残量重复相加。公共池按occupancy的实际m3×小时×对应温区weight分配，独立子表租户已计量部分不再分公共池；占用资料不全时对应比例留待分。reservation只形成场地费，不形成耗电。energy_price为元/kWh，space_price为预留m3每日元；预留与实占不叠加收场地费。移库按move_id形成同一货物的位置区间，不增加体积。

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

独立计量租户的已计量部分不参与公共分配。公共池按未独立计量租户体积时长含温区权重分配，open行给出的体积是暂估分母，其份额保留待分。PUBLIC包含在MAIN内，不能另加在残量之外。

MAIN是设施总表，OLD/NEW是A租户独立计量，PUBLIC是公共负荷子表，其量仍位于MAIN残量中；它不是另一个独立租户。读数假定覆盖前后两个明确读数间累计增量，不能将其伪装成每分钟实测；日集市只能按可证明范围或明确估算标记呈现。场地日费按小时折算，一天24小时。
